# Manesh Toolkit — versioni pubblicate

Questo repository contiene **solo le versioni rilasciate** di Manesh Toolkit:
l'eseguibile di ogni versione, la sua impronta SHA256 e le note di rilascio.
Il codice sorgente non è pubblicato.

## Installazione e aggiornamenti

- Dalla versione **3.31.0** il toolkit controlla all'avvio se qui c'è una
  versione più nuova e propone di installarla.
- Per installare a mano: scarica l'eseguibile dall'ultima
  [release](https://github.com/Biafry/manesh-toolkit-releases/releases/latest)
  e mettilo nella cartella del toolkit, accanto a `Tesseract-OCR` e `lastool`.
- Il file `.sha256` di ogni release serve a verificare che il download sia
  integro: il toolkit lo controlla da solo.
